| `Personal projects` |
| :--- |
_Projects that I build for recreational desires._

- [**hana-wm**](https://github.com/akai-hana/hana-wm): Modular X11 Window Manager, written in Zig.
   > In the same vein of DWM/BSPWM, it features a fully modular architecture design, and lots of usage goodies.
- [**chrysanth**](https://github.com/akai-hana/chrysanth): Optimal X11 shader wallpaper renderer.
   > Renderer tailored specifically for X11 wallpapers (draws directly into X11's root window pixmap).
   > 
   > It ships several QoL config settings, like window auto-pause on fullscreen, compositor auto-killing/respawning, etc.
- [**shirolyzer**](https://github.com/akai-hana/shirolyzer): Alternate keyboard layout analyzer and generator.
   > Determines the most efficient character distribution under defined sets of parameters and conditions.
- [**minecraft-bedrock-finder**](https://github.com/akai-hana/minecraft-bedrock-finder): Minecraft bedrock pattern finder, written in Rust.
   > Anarchy Minecraft utility tool that searches a world's seed spiraling outwards from a given coordinate, until it finds the bedrock pattern specified (which acts like a fingerprint pattern).
   >
   > Includes a friendly GUI to configure and compute.
